Dúvidas Frequentes
🖥️ O Fullscreen não funciona?
Isso é um recurso de segurança nativo do Google Chrome. Sempre que uma extensão captura o áudio de uma aba, o navegador impede o "Fullscreen Verdadeiro" para evitar que páginas falsifiquem sua tela.

Como resolver: Ligue a extensão, clique no botão de tela cheia do site e então aperte F11 no seu teclado. A tela cheia funcionará perfeitamente!
🔒 É seguro? Grava meus dados?
A extensão é 100% segura e não possui rastreadores.
O aviso do navegador de "Captura de Tela/Áudio" aparece porque precisamos escutar o áudio da live para poder traduzi-lo.
O áudio capturado é enviado diretamente aos servidores oficiais da Deepgram (para transformar a voz em texto) e depois ao Google Translate. Nós não armazenamos áudio, textos ou nenhum dado pessoal seu.
🛑 A tradução parou de funcionar?
Como usamos o sistema gratuito do Google Tradutor, se você usar a extensão por muitas horas seguidas, o Google pode bloquear o seu IP temporariamente por excesso de uso.
Caso as legendas parem de aparecer (mesmo com a extensão ligada), basta aguardar algumas horas para que o seu acesso seja liberado automaticamente pelo Google.
🎮 O que é o Modo Esports?
Narrações de jogos (como CS:GO, LoL, Valorant) são muito rápidas e cheias de jargões.
O Modo Esports reduz o delay de captura (trazendo as legendas mais rápido) e ensina a Inteligência Artificial a reconhecer palavras gamer como "clutch", "ace", e "gank".
🔑 Como obter uma API Key?
A extensão precisa de uma chave gratuita da Deepgram para funcionar.
1. Acesse console.deepgram.com e crie uma conta gratuita.
2. No painel, vá em API Keys e clique em Create a New API Key.
3. Copie o código gerado e cole no campo "Deepgram API Key" na aba Geral desta extensão.
(A conta gratuita oferece fundos suficientes para meses de uso diário.)
